# Client - Interview Question Generator (Frontend)

This is the frontend built with **React + Vite + TypeScript**. It allows users to input job details and fetch AI-generated interview questions from the backend API.

## 🚀 Features

- Input form with job title, requirements, and experience level
- Validations using `zod`
- Real-time feedback with `react-toastify`
- Clean UI built with Tailwind CSS

## 📦 Tech Stack

- React
- Vite
- TypeScript
- Zod
- React Toastify
- Axios
- Tailwind CSS

## 🛠 Setup Instructions

```bash
cd client
npm install
```
