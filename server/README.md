# Server - Interview Question Generator (Backend)

This is the backend built with **Express.js + TypeScript** to process incoming job descriptions and generate role-specific interview questions using OpenAI.

## 🚀 Features

- Validates requests using `zod`
- Uses OpenAI GPT-4 to generate structured questions
- Error-handling for validation and runtime issues
- CORS, JSON parsing, static assets

## 📦 Tech Stack

- Node.js
- Express.js
- TypeScript
- Zod
- OpenAI SDK

## 🛠 Setup Instructions

```bash
cd server
npm install
```
